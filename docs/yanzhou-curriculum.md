# 兗州課程與城市設定（2026-11-03）

## 範圍依據

依使用者提供的三張課本截圖，兗州改為五個單元；例句與選擇題重新編寫，不將舊的 There is / are、現在簡單式、have / has 當成本章範圍。

| 課程 ID | 必備內容 |
| --- | --- |
| y2command | 原形／Be、稱呼與逗號、please 位置、do not / don't / never |
| y2lets | Let's + 原形／be、Let's not 與 Don't 的區別 |
| y2can | 能力／許可、原形、肯否直述與問答、否定問句按事實回答、Wh-、can't be 推測 |
| y2or | 同類連接、選擇問答、be 的就近一致、否定兩項、否則 |
| y2object | 七種受格、一般動詞／介系詞受詞、口語 It's me 補語、片語動詞的代名詞位置 |

課末檢核共 25 題；守城測驗每單元兩題，共十題，七題通過。離城十名敵兵只使用兗州題庫。第三章原有內容暫保留為生活應用與複習，不推定未提供的新課本單元。

## 存檔

新課程使用 y2 前綴和 curriculum 版本，不繼承 g5–g7 的精熟度。更新只重設兗州測驗與補給完成狀態，保留舊成績作 legacyBest、資源、武將、其他章節和已解鎖城鎮。已領過的補給資源及章末首通獎勵不再重發。未完成的舊出城戰重置題目進度；完成的路線維持解鎖。

## 三城設計

陳留：190 年募兵街市，義學／募兵館／軍議堂／義軍校場。

兗州：192–196 年立足與守城，以鄄城為據點，學舍／薦才館／守城議事堂／軍需營。兗州是州域，不是一座名為兗州的城。

許都：196 年迎帝都許之後的許縣街區，官署學舍／告示館／議事署／居民驛舍。

三城各自配置街層、樓梯圖、門、居民及武將位置。背景沿用既有 Q 版插畫，不是漢代建築考證復原；橫向多層地形與功能性建築名稱是遊戲設計。

## 史料與改編邊界

- [《三國志》卷一〈武帝紀〉](https://zh.wikisource.org/wiki/三國志/卷01)：192 年青州黃巾入兗州與收編；193 年軍鄄城；194 年張邈、陳宮迎呂布，鄄城、范、東阿固守；195 年平兗州；196 年汝潁討黃巾、迎帝都許。兩段出城戰是教學關卡，不表示當時只有十名敵人或一次戰鬥。
- [《三國志》卷十四〈程郭董劉蔣劉傳〉](https://zh.wikisource.org/wiki/三國志/卷14)：荀彧、程昱守鄄城；郭嘉由荀彧推薦。遊戲保留第二章招募節奏，但不再斷言郭嘉於 196 年特定時間來投；與守城任務的先後是濃縮改編，並不據此斷言他參加 196 年二月汝潁戰役。
- [《三國志》卷十八〈典韋傳、許褚傳〉](https://zh.wikisource.org/wiki/三國志/卷18)：典韋先屬張邈、後屬夏侯惇，194 年從曹操與呂布戰。關卡「典韋來投」改以「典韋效力」呈現，非精確投效日期。許褚歸曹發生在曹操徇淮汝時，不應以他作為 190 年陳留現役教官；改用無名義軍教頭，暫沿用原有角色美術。

荀彧在第一章仍為教學串場角色；此為保留既有教學流程，不主張他在 190 年已投曹。武將在背景戰鬥屬遊戲助戰演出，不是逐場參戰名冊。
