Part B · Grammar6 個文法重點，白話拆開看

01
天氣形容詞：前面要有 be 動詞
sunny / rainy / cloudy / windy...
⌄
形容詞只是在「形容天氣」，自己不能當動詞。句子中要靠 is / was 把主詞和形容詞接起來。
It ＋ is / was ＋ 天氣形容詞（＋ and ＋形容詞）.
現在It is cool and cloudy today.
今天涼爽而且多雲。
過去It was hot and sunny yesterday.
昨天炎熱而且晴朗。
注意：一次放兩個形容詞時用 and 連接。✅ It is cold and snowy.　❌ It is cold snowy.
Yes / No 問句：把 be 動詞移到句首。
Was it rainy last night? → Yes, it was. / No, it wasn't. It was cloudy.
02
How 與 What：兩種天氣問法
How was...? / What was... like?
⌄
問法句型例句
HowHow + be + the weather + 地方／時間?How was the weather there?
那裡的天氣如何？
WhatWhat + be + the weather + like + 地方／時間?What is the weather like in Taipei?
臺北的天氣如何？
最大陷阱：用 What 問時一定要有 like；用 How 問時不能再放 like。
✅ How is the weather?How 後面直接接 be 動詞。
✅ What's the weather like?What 問法的 like 放在後面。
回答方式：用 It 代替 the weather。
It is warm today. / It was cold yesterday.
like 的身分意思與用法
動詞 like「喜歡」：否定或疑問要用 do / does / did。
He doesn't like rainy days.
介系詞 like「像」：前面常有 be 或 look。
That cloud looks like a rabbit.
03
季節前面的 in：有些時候要拿掉
in summer，但 this summer
⌄
情況正確用法白話判斷
泛指季節in spring / summer / autumn / fall / winter沒有指定哪一年，就用 in。
有 this / lastthis summer / last winter前面已有「今年／去年」的意思，不再加 in。
✅ It rains a lot in summer.夏天常下很多雨。
✅ It snowed last winter.去年冬天下過雪。
常見錯誤：in last winter。看到 this / last＋季節，直接把 in 拿掉。
04
rain / snow 當動詞：主詞只用 it
現在、過去、進行式都能變
⌄
It ＋ rains / rained / is raining ＋（a lot）＋地方／時間.
It ＋ snows / snowed / is snowing ＋（a lot）＋地方／時間.
句型rain 範例snow 範例
肯定It rains a lot here.It snowed yesterday.
否定It doesn't rain much here.It didn't snow last night.
疑問Does it rain a lot here?Did it snow last night?
為什麼用 does / did？因為這裡的 rain / snow 是一般動詞。現在式第三人稱 it 用 does；過去式用 did，後面的 rain / snow 都回原形。
數量副詞：肯定句常用 a lot；否定或疑問常用 much / very much。它們放在動詞後面修飾「下得多不多」。
05
rain / snow 當名詞：前面要有數量詞
have / there be + a lot of rain
⌄
當 rain / snow 表示「雨／雪」這種東西時，是不可數名詞。前面可以用 a lot of / lots of；不能加 -s 來表示很多。
We / They ＋ have / had ＋ a lot of / lots of ＋ rain / snow.
There ＋ is / was ＋ a lot of / lots of ＋ rain / snow.
have 句型We have lots of rain in summer.
我們夏天雨量很多。
there be 句型There was a lot of snow last winter.
去年冬天雪量很多。
問句／否定：Do you have much rain here? / There wasn't much snow. 日常肯定句通常用 a lot of / lots of，比 much 自然。
一秒判斷：rain / snow 前面若有 a lot of、lots of、much，後面就是名詞；若前面直接是 it，通常就是動詞。
06
給、寄、借：人與物怎麼排
to 是方向；for 是「替某人」
⌄
動詞人放前面物放前面
givegive me a giftgive a gift to me
sendsend me a postcardsend a postcard to me
lendlend me your gloveslend your gloves to me
buybuy me a jacketbuy a jacket for me
makemake me some teamake some tea for me
記憶法：give / send / lend 的東西會「移動到某人那裡」，所以用 to；buy / make 是「替某人做事」，所以用 for。
字視角例句
borrow從別人那裡借進來I borrowed a snowboard from my aunt.
lend把自己的東西借出去My aunt lent a snowboard to me.
不能混用：borrow me a pen。要說 lend me a pen，或 let me borrow a pen。

Part C · Phrases片語與實用句型

write to 人
寫信給某人
write a letter to Grandma；若是「替奶奶寫」才用 for。
buy 物 for 人
買某物給某人
buy a jacket for me＝買一件夾克給我。
send 物 to 人
寄／送某物給某人
也可把人放前面：send me a postcard。
make 物 for 人
為某人製作某物
make dinner for us＝替我們做晚餐。
another time
另一次；改天
another 後面接單數名詞 time。
coming right up
馬上來
餐廳接到點餐後常用：Your order is coming right up.
under the weather
身體不舒服
這是慣用語，不是真的「在天氣下面」。

高興極了
形容非常開心、像飄在雲端。

用來補充真正情況，句首後面通常加逗號。
have a good time
玩得開心
也可說 have fun；兩者都很常用。

Part D · Review考前 7 句快速收尾

📌 看到題目，先套這 7 個骨架

1. 天氣形容詞：It is / was + sunny, rainy, cloudy...
2. How 問天氣：How is / was the weather + 地方／時間?
3. What 問天氣：What is / was the weather like + 地方／時間?
4. rain / snow 動詞：It rains / rained；疑問用 Does / Did it...?
5. rain / snow 名詞：have / there be + a lot of rain / snow。
6. 借入借出：borrow 物 from 人；lend 人 物＝lend 物 to 人。
7. 人與物：give / send / lend 用 to；buy / make 用 for。
